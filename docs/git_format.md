# Git提交规范

## 示例 1：新增功能

```plaintext
feat(user): 添加用户登录功能
- 新增登录页面
- 集成 JWT 认证
- 添加登录表单验证逻辑

Closes #123
```

**说明**：  
• `feat` 表示新增功能。  
• `user` 是功能范围，表示用户模块。  
• 正文详细描述了新增的功能。  
• `Closes #123` 表示该提交关闭了 Issue #123。

---

## 示例 2：修复 Bug

```plaintext
fix(auth): 修复登录页面样式错乱问题
- 调整登录表单的 CSS 样式
- 修复按钮对齐问题

Closes #456
```

**说明**：  
• `fix` 表示修复 Bug。  
• `auth` 是功能范围，表示认证模块。  
• 正文详细描述了修复的内容。

## 示例 8：回滚提交

```plaintext

```

**说明**：  
• `revert` 表示回滚提交。  
• 正文说明了回滚的具体提交。
